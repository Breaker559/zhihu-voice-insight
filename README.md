# 知乎发言画像（zhihu-voice-insight）

看回答之前，先看看答主是谁。一个油猴脚本，在知乎每条内容的**作者行下方**直接标注该答主的发言频率、最近发言和正文字数，并自动识别短时间连发的刷屏账号，可按规则折叠或隐藏。

## 长什么样

折叠态只占一行，跟页面其他灰色小字融为一体：

```
近 7 天 4 条 · 30 天 11 条 · 间隔 3.5 天 · 均 1480 字              最近 5 条 ▾
```

命中刷屏规则时底色转为暖色，并在左侧带一条橙色竖条：

```
近 7 天 62 条 · 30 天 180 条 · 间隔 1.8 小时 · 均 38 字  [1 小时内连发 6 条] [短句灌水]
```

点「最近 5 条 ▾」展开，每条压成一行，时间具体到分钟：

```
为什么现在年轻人都不愿意结婚了？                          42字  10-19 17:26
怎么看最近这个热搜？                                      28字  10-19 17:22
如何看待某明星官宣恋情？                                  35字  10-19 17:18
────────────────────────────────────────────────────────────────────
样本 20 条 · 最新 10-19 17:26 · 中位 36 字 · 最长 90 · 日均 8.6 条
```

## 功能

**统计**

- 近 7 天 / 近 30 天发言条数、平均发言间隔
- 平均 / 中位 / 最长正文字数
- 注册天数、历史日均、累计条数
- 回答与文章合并统计，按时间混排

**最近发言**

- 标题、类型（回答/文章）、具体时间（到分钟）、赞评数、正文字数
- 字数默认按字符数统计；接口只给摘要时数字前标 `≈`

**刷屏识别**（用滑动窗口算「任意时间窗内的最大条数」，能抓到同一分钟连发）

| 规则 | 默认阈值 |
| --- | --- |
| 1 分钟内 ≥ N 条 | 2 |
| 5 分钟内 ≥ N 条 | 3 |
| 1 小时内 ≥ N 条 | 4 |
| 24 小时内 ≥ N 条 | 10 |
| 平均间隔 < N 小时（样本 ≥ 5） | 6 |
| 注册 ≤ 30 天且累计 ≥ 30 条 | 新号高产 |
| 平均 < 50 字且近 30 天 ≥ 10 条 | 短句灌水 |

阈值把某条填 0 就是关掉那条规则。

**处理方式**（命中后，按你在设置里选的力度执行）

- `仅标记`：回答不动，只加橙色左边线
- `折叠`：回答收起，顶部留一条 `已折叠：1 小时内连发 6 条｜展开｜不再屏蔽`
- `隐藏`：整个回答从页面消失

面板上的「屏蔽此人」可手动拉黑单个作者；加入白名单的账号只标记、永不折叠。

## 安装

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox 均可）
2. 点 Tampermonkey 图标 → 「添加新脚本」→ 把 [`zhihu-voice-insight.user.js`](./zhihu-voice-insight.user.js) 的内容整段粘贴进去覆盖 → 保存
3. 首次运行会弹一次授权确认（`www.zhihu.com` 等域名），点允许

也可以直接在 Tampermonkey 里用 URL 安装本仓库的 raw 地址。

## 使用

- 打开任意知乎页面（首页推荐流、问题页、回答页、专栏）即可自动标注，翻页 / 无限滚动会自动补扫
- 右下角「发言画像」按钮打开设置面板：阈值、计数口径、抓取条数、模式、重新扫描、清空缓存
- 油猴菜单里的命令：

| 命令 | 作用 |
| --- | --- |
| 启用 / 暂停标注 | 临时关掉不占资源 |
| 切换展开条数 | 4 / 6 / 10 / 15 条循环切换 |
| 清空缓存 | 强制重新请求接口 |
| 控制台自检 | 打印接口返回的原始长度与字数，用于排查取数问题 |

## 说明

- **需要浏览器已登录知乎**。未登录时接口返回受限，面板会提示并给出直达主页的链接。
- 数据来自知乎 `api/v4` 接口。若被拦截（签名校验等），会自动退回到抓取 `/people/{token}/answers` 页面 HTML 并解析其中的 `js-initialData`，不至于整个失效。
- 结果按用户缓存 30 分钟，同一页面反复出现同一答主不会重复请求。
- 正文字数依赖接口返回完整 `content`；列表接口默认只给摘要，脚本已显式传 `include=data[*].content`。若仍拿不到正文，字数前会标 `≈`。
- 本脚本只读数据，不做任何写入操作，也不向知乎以外的地址发请求。

## 排查

字数明显不对或一直显示 `≈`：点油猴菜单的「控制台自检」，看 `content 原始长度`。若稳定在 100 上下，说明 `include` 参数没生效；若接近真实正文长度，则是接口确实只返回了摘要。

面板位置错乱（压住昵称、挤在头像旁边）：把页面类型和截图发 issue，脚本靠「从作者链接向上找含正文块的祖先」定位卡片，个别页面结构需要补选择器。
